# KindLink
I created this application for the course 26S Server-Side Scripting - ASP.NET. The purpose of the application is to connect volunteers with organizations. Each organization can post as many volunteer opportunities as they want to, but each post must have just one organization assigned to it (a 1-to-many relationship).

## Tecnology
I used Rider as my IDE and coded using C# with the ASP.NET MVC pattern.

## Models
- Organization
- VolunteerPosition
- Volunteer
